# AI Router 首版需求

确认日期：2026-11-16。用户确认目标为腾讯 WorkBuddy + 本机 ChatGPT 登录的 Codex 额度。

## 目标与范围

Windows 上提供可直接打开的桌面控制台，把本机 Codex 的推理能力转为 WorkBuddy 可配置的自定义模型服务。由 Codex 管理 ChatGPT 身份和推理用量，由 WorkBuddy 保持其任务编排与工具执行。

首版提供：登录检测、服务启停、模型目录、用量窗口、接入参数复制、真实连接测试、端口和 Codex 路径设置、内存运行记录。退出应用停止服务。

首版不包含：用量转账、账号共享、多账户池、自动切换账号、云端托管、局域网服务、托盘、自动更新和开机启动。

## 核心验收

1. 已通过 ChatGPT 登录且 Codex 可运行时，应用展示账户计划、模型目录和服务返回的用量窗口；缺失用量数据显示未知。
2. 点击启动后，服务监听本机回环地址；WorkBuddy 可使用自定义模型参数发起请求。
3. 文本请求收到真实 Codex 回答，SSE 请求收到增量和结束事件。
4. 模型请求 WorkBuddy 工具时，返回标准 `tool_calls`；WorkBuddy 回传结果后，Codex 继续生成回答。
5. 取消、断连、失败、超时和过期工具会话返回明确错误；失败回答不标记为成功。
6. 停止或退出后，接口监听关闭，并停止应用拥有的 Codex app-server 子进程。
7. 无效密钥、非本机 Host 和网页跨域调用不能访问推理接口。

## 尚需客户端验证

需要在用户实际安装的 WorkBuddy 版本验证：自定义 API URL 补全、工具标记、并行工具、历史消息形态、长任务超时、图片输入、取消和客户端重试。冒烟测试通过不等同于 WorkBuddy 全功能兼容。

## 技术选择

Electron 桌面壳 + Node.js 本机 HTTP 服务；stdio JSON-RPC 连接已安装的 Codex app-server，不读取或转发其登录令牌。会话采用内存状态与动态工具原始请求映射；实验协议变化由适配层处理。
